Connect Spotify

Two quick steps. Spotify can’t send you straight back to this app on a home network, so you’ll copy one address across.

1. Approve access

RunningTime will only be able to create private playlists in your account. It can’t see your library or listening history.

Open Spotify

After you tap Agree, the next page will say it can’t be reached (the address starts with {{ redirect_uri.split('?')[0] }}). That’s expected.

2. Paste the address

On that page, tap the address bar and copy the whole address, then come back to this page and paste it here.

The address holds a one-time code that only this server can use. It expires in 15 minutes.
